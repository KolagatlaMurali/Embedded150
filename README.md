# Embedded 150 🚀

## Overview

**Embedded 150** is a structured learning repository focused on **core embedded systems concepts**, starting from the basics and gradually moving toward advanced topics.

This repository is designed for:
- Beginners entering embedded systems
- Engineers revising fundamentals
- Interview preparation
- Hands-on understanding through simple and focused examples

The content emphasizes **concept clarity**, **practical examples**, and **industry-relevant embedded topics**.

---

## Repository Structure

Each topic in this repository is organized using **branches**.

🔹 **One topic → One branch**

This keeps the `main` branch clean and allows focused learning per topic.

---

## Branch Strategy

- The **`main` branch** contains:
  - This README file
  - Overall repository information

- **Individual topics** are implemented in **separate branches**
  - Each branch contains code related to **one embedded concept**
  - Example:
    - `linked-list`
    - `makefile-basics`
    - `gpio-basics`
    - `uart-communication`

📌 **Note:**  
The code for a particular topic will be added only to its corresponding branch.



## How to Use This Repository

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. List available branches:
   ```bash
   git branch -a
   ```

3. Checkout a specific topic branch:
   ```bash
   git checkout <branch-name>
   ```

4. Explore the code and README inside that branch.
